Key Security Concepts Demonstrated

1. Algorithmic Complexity Attack (Hash DoS): Standard hash maps offer O(1) average lookup time. However, if an attacker crafts keys that hash to the same bucket index, lookups degrade to O(N) linear searches. When 50 entries collide in a single bucket, search overhead causes a 100% CPU spike and memory overflow glitches.

2. Side-Channel Attack (Timing Attack): Standard string comparison functions exit early on the first mismatched character. By measuring small execution time discrepancies (e.g., matching 1 digit takes 25ms, 2 digits take 40ms), an external attacker can brute-force secrets digit-by-digit rather than trying all combinations.
