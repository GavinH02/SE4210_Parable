# SE4210_Parable
This is a github repo for demonstrative html pages to show how certain user inputs can be risky and result in vulnerabilities in the webpage and overall integrity of applications.

## Overflow Parable
This is a small interactive website that asks the user for different inputs, when the user overflows those inputs something on the webpage changes. This will help beginner programmers visualize the importance of input verification.

## Attack Parable
This is another small interactive webpage that demonstrates algorithmic complexity attacks and side channel attacks. (Hint use 421 to enter debug to complete the side channel attack)

## How to run it
These simple html webpages are easy to use, simply download and open the html file with a browser, whether that be integrated with an IDE, or simply opening the file with your browser of choice in file explorer.
IMPORTANT NOTE: This was designed and tested with Edge, there is no guarantee it will look good or function on another browser.
